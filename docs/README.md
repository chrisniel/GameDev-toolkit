# Documentation Index

This directory follows the standardized **Docs_ProjectWorkflowStarterKit_v2.0** lifecycle hierarchy, separating drafts, tracking, planning, walkthroughs, architecture, design, guides, and archives.

The active repository deliverable is the 17-skill `GameDev Workflow Toolkit`. Its completed specialization is documented in [`03_Walkthroughs/gamedev-workflow-toolkit-specialization.md`](03_Walkthroughs/gamedev-workflow-toolkit-specialization.md).

For client-specific setup and safe cross-client sessions, read [`06_Guides/skill-portability.md`](06_Guides/skill-portability.md). The skills-only strengthening is explained in [the portability walkthrough](03_Walkthroughs/unity-skills-portability.md).

The repository's source attribution and private-use boundary are recorded in [`06_Guides/provenance.md`](06_Guides/provenance.md). This text-only record intentionally excludes screenshots, private account identifiers, and private contact details.

## Standard Lifecycle Folders

- `00_Drafts/` — (Ignored by default) sketches, unreviewed notes, and unapproved future plans.
- `01_Tracking/` — active `task.md` (capped at 80 lines) and historical `task_archive.md`.
- `02_Planning/` — technical implementation plans, pseudocode, and QA acceptance criteria.
- `03_Walkthroughs/` — beginner-friendly delivery explanations and developer handovers.
- `04_Architecture/` — system contracts, data models, and technical specs.
- `05_Design/` — game design documents, UI/UX specs, narrative scripts.
- `06_Guides/` — onboarding, testing standards, setup guides, and contributor workflows.
- `07_Archive/` — (Ignored by default) deprecated audits, superseded drafts, and old notes.

## Authority Order

1. Explicit current user instructions.
2. `AGENTS.md` repository rules.
3. `02_Planning/implementation-plan.md` for the approved roadmap.
4. `01_Tracking/task.md` for current state and continuity.
5. Walkthroughs in `03_Walkthroughs/` for completed-delivery explanation.
6. `00_Drafts/` as non-authoritative reference material.

Do not treat a draft, example, or walkthrough as approval for new implementation work.

## Reusable Starter Kit

See `ProjectWorkflowStarterKit/project-workflow-starter-kit.md` for the component card and reference manual. Copy blank templates from `ProjectWorkflowStarterKit/` or the corresponding folders rather than populated tracking files.
