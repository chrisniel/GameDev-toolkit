# Documentation Index

This directory separates draft material, completed-delivery walkthroughs, and active tracking.

The active repository deliverable is the 17-skill `GameDev Workflow Toolkit`. Its completed specialization is documented in [`07_Walkthrough/gamedev-workflow-toolkit-specialization.md`](07_Walkthrough/gamedev-workflow-toolkit-specialization.md).

For client-specific setup and a safe first Kumpuni session, read [skill-portability.md](skill-portability.md). The skills-only strengthening is explained in [the portability walkthrough](07_Walkthrough/unity-skills-portability.md). The custom MCP remains future planning, not a skill dependency.

The repository's source attribution and private-use boundary are recorded in [`provenance.md`](provenance.md). This text-only record intentionally excludes screenshots, private account identifiers, and private contact details.

## Canonical Folders

- `00_Draft/` — sketches, reference material, and unapproved future plans.
- `07_Walkthrough/` — beginner-friendly explanations for meaningful completed deliveries.
- `08_Tracking/` — the active implementation roadmap and task-continuity record.

Numbered folders use the first suitable available number. If a future repository already uses `07`, use `08`, then `09`, and continue upward until an unused number is found. Once selected, update `AGENTS.md` and all canonical links together.

These paths describe this repository only. The reusable starter kit supports different numbered folders, unnumbered folders, root-level tracking files, or `Not used` documentation features through the `AGENTS.md` Project Profile.

## Authority Order

1. Explicit current user instructions.
2. `AGENTS.md` repository rules.
3. `08_Tracking/implementation-plan.md` for the approved roadmap.
4. `08_Tracking/task.md` for current state and continuity.
5. Walkthroughs for completed-delivery explanation.
6. `00_Draft/` as non-authoritative reference material.

Do not treat a draft, example, or walkthrough as approval for new implementation work.
