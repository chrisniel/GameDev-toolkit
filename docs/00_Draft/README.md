## Starting A New Project

Copy only the reusable baseline and blank templates—not this repository's completed task history or implementation plan:

1. Copy the root `AGENTS.md` into the new repository root.
2. Copy `task-template.md`, `implementation-plan-template.md`, and `docs/07_Walkthrough/walkthrough-template.md` into whatever folders the new project will use.
3. Rename the template copies if the new repository uses different canonical names.
4. Edit every value in the new `AGENTS.md` **Project Profile** so it points to those real locations.
5. Set unused paths or requirements to `Not used` instead of leaving broken references.
6. Replace the project-specific protected boundaries and manual-verification areas.
7. Confirm every configured path exists before using the files for implementation work.

The folder numbers `07` and `08` are current-project choices, not requirements of the starter kit. Another project may use numbered folders, unnumbered folders, root-level files, or no persistent walkthrough/changelog system.
