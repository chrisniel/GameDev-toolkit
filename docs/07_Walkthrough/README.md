# Walkthrough Documentation

Use this folder for meaningful completed deliveries and feature implementations. A walkthrough teaches another developer or the user what changed, how the important logic works, how to verify it, and how to customize it safely.

Start from `walkthrough-template.md`. Replace every bracketed placeholder and remove unused optional sections.

The folder number is repository-specific. `07_Walkthrough` is canonical here because `07` was available when the folder was created.
