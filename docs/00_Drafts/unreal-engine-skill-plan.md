# Unreal Engine Skill — Future Plan

**Status:** Planning only; implementation is not approved in Phases 0–5.

## Intended Scope

A future Unreal Engine skill may cover:

- repository and `.uproject` onboarding;
- C++ modules and Blueprint boundaries;
- levels, assets, input, gameplay framework, and configuration;
- generated folders and editor-managed asset safety;
- compilation, automation tests, and packaged-build checks when available;
- explicit user-owned editor, visual, performance-feel, and device verification.
