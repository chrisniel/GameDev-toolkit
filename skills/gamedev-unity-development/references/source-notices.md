# Unity Workflow Source Notices

Reviewed 2026-09-03. The adaptation in `unity-editor-workflows.md` draws on these versioned CoplayDev sources:

- [Operator guide, v10.1.2](https://github.com/CoplayDev/unity-mcp/blob/v10.1.2/unity-mcp-skill/SKILL.md): context before action, compilation and console checks, visual evidence, paginated results, instance selection, and reload recovery.
